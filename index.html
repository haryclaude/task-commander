The Method

5 rules, applied in strict order

Rule 1

Flag Errors

Kill duplicates, stale tasks, impossible items before they waste time.

Rule 2

Ignore Noise

No action, no impact, no deadline, no consequence? It's not a task.

Rule 3

Check Dependencies

Never rank a task above the thing blocking it.

Rule 4

Check Ownership

Does it need your judgment? Own it. Can someone else execute? Delegate it.

Rule 5

Score & Rank

Weighted formula. Deterministic tie-breakers. Same input → same output.
